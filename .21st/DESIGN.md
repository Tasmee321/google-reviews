# Tasmee Personal Reviews design context

Existing application: Flask/Jinja with vanilla HTML, CSS and JavaScript. Preserve the dark navy surfaces, blue action color, Segoe UI typography and compact dashboard density.

History/monitor update: 21st metadata inspiration from Invoice History Table
(cnippet-dev, demo 22187) and Audit Log Table (arihantcodes_1f7b8c4d, demo 29266).
No paid source retrieval or React installation: existing native controls reused.
Separate row detail/delete buttons, text-plus-color status badges, native
confirmation dialog, labelled filters and shortcut selector preserve the design.
21st CLI is unavailable; connector search and project tests were used instead.

The personal workflow has one composer, one Google connection panel, a verified preview and recent review history. Use native controls, labelled fields, radio-based ratings, visible keyboard focus, linked error summaries and clear pending/error states. Keep the form usable at 375px and under reduced motion.

21st catalog search returned Star Rating (arihantcodes_1f7b8c4d, demo 29301) as interaction inspiration. No React code was retrieved or installed; native radios fit this Flask project. CLI search could not authenticate; metadata was obtained through the installed 21st connector.
